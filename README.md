# Fraud Detection Using Machine Learning

A complete end-to-end Machine Learning project to detect fraudulent transactions using XGBoost and deploy the solution with Streamlit. This project demonstrates real-world problem-solving, model evaluation, and app deployment.

---

## Overview

This project aims to identify fraudulent financial transactions using classification techniques. It involves:

- Data cleaning & preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- Handling imbalanced data
- Model building with XGBoost
- Model evaluation (Precision, Recall, F1-score)
- Streamlit app deployment

## Model Performance

- **Precision**: 0.05–0.06 (due to high class imbalance)
- **Recall**: ~0.99 (captures almost all fraud cases)
- **Best Model**: XGBoost
